# Object Detection Model Training Module

## Product Tagging in VEO360 Digital Twin Using Object Recognition

This module is responsible for training the object detection model used in the VEO360 Product Tagging solution.

The script fine-tunes a pre-trained YOLOv8 model using the synthetic dataset generated in the previous stage of the pipeline. The resulting detector is capable of identifying industrial assets, such as ABB REX615 relays, within Digital Twin imagery and panoramic scans.

---

# Purpose

The objective of this module is to transform the synthetic dataset into a production-ready object detection model that can recognize industrial equipment in VEO360 digital twin environments.

This script:

- Loads a pre-trained YOLOv8 model
- Uses synthetic training datasets
- Applies industrial-focused data augmentation
- Fine-tunes model weights
- Evaluates detector performance
- Exports the best-performing model

The trained detector is later used during asset identification and automatic tagging.

# What This Script Does

The script performs end-to-end detector training using YOLOv8.

## Features

### Dataset Validation

Before training starts, the script verifies that the dataset configuration file exists.

Example:

```text
data/synthetic/data.yaml
```

If the dataset is missing, training stops and prompts the user to generate synthetic data first.

---

### Automatic Hardware Detection

The script automatically selects the best available compute platform.

```python
torch.cuda.is_available()
```

Possible execution modes:

```text
CUDA GPU
CPU
```

If no GPU is available:

- CPU training is used
- Batch size is reduced automatically

This helps prevent memory issues during training.

---

### Transfer Learning

The trainer loads a pre-trained YOLOv8 model.

Default model:

```text
yolov8s.pt
```

Other supported models:

```text
yolov8n.pt
yolov8s.pt
```

Using transfer learning significantly reduces training time and improves performance with smaller datasets.

---

### Fine-Tuning

The model is trained using the generated synthetic dataset.

Training includes:

- Weight optimization
- Feature learning
- Object localization
- Asset classification

The script uses:

```python
optimizer="AdamW"
```

for efficient convergence.

---

### Industrial Data Augmentation

Additional augmentations are applied during training to improve robustness in industrial environments.

Configured augmentations include:

#### HSV Variations

```python
hsv_h = 0.015
hsv_s = 0.7
hsv_v = 0.4
```

Simulates:

- Camera differences
- Lighting conditions
- Color variation

---

#### Rotation

```python
degrees = 10.0
```

Simulates tilted equipment views.

---

#### Translation

```python
translate = 0.1
```

Improves positional robustness.

---

#### Scaling

```python
scale = 0.2
```

Allows recognition at different distances.

---

#### Horizontal Flipping

```python
fliplr = 0.5
```

Improves viewpoint variation.

---

#### Mosaic Augmentation

```python
mosaic = 0.5
```

Combines multiple images into a single training sample, increasing dataset diversity.

---

### Validation

After training completes, the model is validated automatically.

Evaluation metrics include:

```text
mAP@50
mAP@50-95
```

These metrics provide an indication of:

- Detection accuracy
- Localization quality
- Overall model performance

# Running the Script

## Basic Usage

```bash
python 03_train_detector.py
```

This uses the default configuration.

---

## Custom Training Run

```bash
python 03_train_detector.py \
    --data data/synthetic/data.yaml \
    --epochs 50 \
    --imgsz 640 \
    --batch 16
```
