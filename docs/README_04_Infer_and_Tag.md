# Intelligent Asset Detection and Digital Twin Tagging Module

## Product Tagging in VEO360 Digital Twin Using Object Recognition

This module is the final stage of the VEO360 Product Tagging pipeline. It combines object detection, OCR, document retrieval, and 3D coordinate estimation to automatically generate intelligent asset tags for Digital Twin environments.

The script processes scan images, detects equipment, extracts identifying text, links documentation, estimates spatial positions, and exports structured tag information for integration into the VEO360 Digital Twin platform.

---

# Purpose

Industrial Digital Twins often require engineers to manually:

- Locate assets
- Identify equipment
- Create tags
- Attach documentation
- Record metadata

This module automates the process.

The script:

- Detects equipment using a trained YOLOv8 model
- Performs OCR on detected assets
- Identifies products such as ABB REX615 relays
- Retrieves documentation metadata
- Estimates 3D Digital Twin locations
- Generates intelligent tags
- Creates visualization overlays
- Exports Digital Twin integration data

# What This Script Does

The script performs intelligent asset recognition and Digital Twin tag generation.

## Features

### Object Detection

The script loads a trained YOLOv8 model and scans panorama images.

Example:

```python
model = YOLO(weights_path)
```

Detected assets receive:

- Bounding boxes
- Detection confidence
- Class labels

Example output:

```text
REX615
Confidence: 0.94
```

---

### OCR-Based Product Verification

If EasyOCR is installed, the script performs OCR on detected assets.

Example:

```python
easyocr.Reader(["en"])
```

The OCR process extracts visible text from equipment labels.

Examples:

```text
REX615
ABB
615
```

This provides a second layer of verification beyond object detection.

---

### Product Identification

Detected products are mapped to known equipment.

Example registry entry:

```json
{
  "REX615": {
    "asset_name": "ABB Relion REX615 Protection & Control Relay",
    "manufacturer": "ABB"
  }
}
```

If OCR detects keywords such as:

```text
REX
615
```

The system automatically associates the detection with the correct asset type.

---

### Documentation Retrieval

The script loads a documentation registry.

Example:

```json
asset_registry.json
```

Information may include:

- Product manuals
- Wiring diagrams
- Manufacturer information
- Maintenance metadata
- Inspection records

Example:

```json
{
  "documentation_url": "...",
  "wiring_diagram_url": "..."
}
```

This information is attached directly to the generated Digital Twin tag.

---

### 3D Spatial Position Estimation

The script estimates Digital Twin coordinates using the detected object's position within a panorama.

Input:

```text
2D Pixel Coordinates
```

Conversion:

```text
Pixel Position
      │
      ▼
Spherical Coordinates
      │
      ▼
Cartesian Coordinates
```

Generated values:

```json
{
  "yaw_deg": 45.2,
  "pitch_deg": -8.5,
  "x": 1.72,
  "y": -0.37,
  "z": 1.88
}
```

These coordinates can be used by VEO360 to anchor tags inside the Digital Twin.

---

### Intelligent Tag Creation

Each identified asset receives a unique tag.

Example:

```text
TAG-0001
TAG-0002
TAG-0003
```

Generated information includes:

- Asset ID
- Detection confidence
- OCR results
- Product metadata
- Documentation links
- Estimated 3D coordinates

---

### Visual Overlay Generation

Annotated scan images are automatically created.

Example:

```text
Original Scan
     │
     ▼
Bounding Box
     │
     ▼
Asset Name
     │
     ▼
Tag Identifier
```

Example label:

```text
[TAG-0001] REX615 (0.94)
```


```bash
    --weights models/rex615_detector/weights/best.pt \
```

# Internal Processing Workflow

## Step 1

Load Documentation Registry

```python
load_doc_registry()
```

Output:

```text
Asset Metadata
Documentation Links
```

---

## Step 2

Load YOLO Model

```python
YOLO(weights_path)
```

Output:

```text
Object Detector
```

---

## Step 3

Initialize OCR

```python
easyocr.Reader()
```

Output:

```text
Text Recognition Engine
```

---

## Step 4

Detect Assets

```python
model.predict()
```

Output:

```text
Bounding Boxes
Class Labels
Confidence Scores
```

---

## Step 5

Run OCR

Detected regions are cropped.

```python
roi = image[y1:y2, x1:x2]
```

OCR extracts visible text for verification.

---

## Step 6

Match Documentation

Assets are matched to registry entries.

Example:

```text
REX615
```

↓

```text
ABB Documentation
Wiring Diagram
Maintenance Data
```

---

## Step 7

Compute 3D Coordinates

```python
pixel_to_spherical_coordinates()
```

Generates:

```text
Yaw
Pitch
X
Y
Z
```

for Digital Twin placement.

---

## Step 8

Generate Asset Tags

Example:

```json
{
  "tag_id": "TAG-0001",
  "asset_key": "REX615",
  "confidence": 0.94
}
```

---

## Step 9

Create Visual Overlays

Bounding boxes and labels are drawn onto scan images.

Output:

```text
tagged_scan_001.jpg
```

---

## Step 10

Export Digital Twin Data

Final result:

```json
tags.json
```

containing all generated tags.
